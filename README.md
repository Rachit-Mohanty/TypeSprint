TypeSprint ⌨️🚀
TypeSprint is a modern, full-stack web application designed to track typing speed and improve developer productivity through AI-generated custom code drills.

Tech Stack

Frontend: React, Vite

Backend: Node.js, Express

AI Integration: Google Gemini API

Data & Storage: LocalStorage analytics, Global Leaderboard

Core Features

Dynamic Code Drills: Practice with standard text or AI-generated custom code snippets tailored to your skill level.

AI Coaching: Receive personalized feedback on your typing accuracy, speed, and areas for improvement.

Global Leaderboard: Securely submit your WPM and compete with other developers worldwide.

Deep Analytics: Track your WPM, session duration, and character accuracy over time.

Getting Started

Clone the repository and install dependencies in both the client and server directories.

Create a .env file based on .env.example and add your GEMINI_API_KEY strictly to the backend environment.

Start the backend Node.js server (server.ts).

Boot up the Vite frontend development server.
